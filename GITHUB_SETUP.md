## Upload

Create an empty GitHub repository with the suggested name. Do not initialize it with a README, license, or gitignore: those files are already supplied here.

Unzip the download, open a terminal inside the `robotics-ii-mobile-robotics` directory, and run:

```bash
git init
git add .
git commit -m "Organize Robotics II mobile robotics semester project"
git branch -M main
git remote add origin https://github.com/tsimiho/robotics-ii-mobile-robotics.git
git push -u origin main
```

The remote assumes the GitHub username `tsimiho` and the exact suggested repository name; change it if needed. Set the description and topics in the repository's About settings. The upload commands apply to a new empty repository; do not use them to overwrite an existing project's history.
